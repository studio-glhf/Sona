# Sona terminology register

PRD version: 1.0. Standard: ASD-STE100 Issue 9, 15 January 2025.

This register defines the technical terms used in Sona. It is not an ASD-approved dictionary supplement. It does not permit unrestricted use of a word. The meaning, part of speech, and context must agree with the entry.

## Basis

Rule 1.5 permits technical nouns in specified categories. Rules 1.6–1.11 control their selection and use. Rule 1.12 permits necessary technical verbs. Rule 1.13 keeps noun and verb uses separate. Rule 3.5 permits an “-ing” form as a technical noun or its modifier.

Use an approved ordinary word when it gives the correct meaning. Do not classify ordinary prose as technical vocabulary to avoid a dictionary restriction. For example, “check” and “test” stay nouns. “Provide” becomes “give.”

“Agent” needs special attention. The dictionary approves this noun for a material used in a process. Sona uses “agent” for an AI system. That use needs the computing category. The ordinary dictionary entry does not approve that meaning.

## Technical verbs

These are proposed computer-process verbs under rule 1.12, category 2. The table specifies the software operation. It does not approve the word in unrelated prose. Use an approved verb where it gives the same accurate instruction.

| Verb | Software operation and limit |
|---|---|
| Authenticate | Validate account identity through the configured authentication protocol. |
| Authorize | Grant a specified permission to a connected account or tool. |
| Bind | Attach a server listener to an address, or attach approval to a proposal identifier. |
| Block | Prevent a specified software operation through an access or state check. Use “prevent” in ordinary prose. |
| Call | Invoke an API or tool operation. Do not use it as a replacement for “name.” |
| Cancel | Send a cancellation or stop a pending software operation. Do not imply reversal of an external write. |
| Capture | Take microphone input or protocol data into the configured processing path. |
| Configure | Set software values and connections. |
| Delete | Remove a stored object through the defined deletion operation. |
| Disable, enable | Change the enabled state of a software function. |
| Execute | Perform a specified API or tool operation. |
| Export, import | Transfer data through a specified portable format. |
| Filter | Select records by a specified predicate. |
| Reconcile | Determine an uncertain write outcome from service records or an idempotency identifier. |
| Reconnect | Make a new protocol connection after disconnection. |
| Retry | Send another attempt for the same operation under its retry policy. |
| Run | Execute software or a configured session. Use “operate” where that gives the same meaning. |
| Save, store | Write persistent data. “Saved” is a storage state, not evidence that the provider applied a setting. |
| Scroll | Move the viewport through content. |
| Validate | Apply a schema or access rule to software data. |
| Escape | Encode CSV input so that spreadsheet software does not execute it as a formula. |

These verbs can have regular past and participle forms in their specified contexts. A noun with the same spelling needs a separate noun classification. A technical verb does not permit a progressive tense.

## Labels and identifiers

Keep provider identifiers and existing product names unchanged. Examples include `audio.output.speed`, `create_response`, and `mcpServer/tool/call`. These are technical identifiers, not instructions written in ordinary English.

New Sona labels need a language examination. Do not claim that rule 8.6 exempts new labels from the vocabulary rules. That rule controls counting and the treatment of text which cannot change.

The figures show one design with three application surfaces. Their labels use the same names as the requirements. Example transcripts represent session evidence, not writing instructions.

## Editorial use

Use this register with the supplied standard. Examine the meaning and part of speech in the full sentence. A matching spelling does not prove a permitted use.

Researcher view and Participant view identify two interfaces. They do not identify account roles. A researcher can be the participant without a view change.

Graph, timeline, protocol deviation, and researcher participation are research terms in this specification. Device selection, handoff, and draft describe defined software functions.

This revision uses editorial judgment. It does not use the previous Python checker, a sentence score, or an automated compliance gate.
