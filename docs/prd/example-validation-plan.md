# Optional example: speech-speed comparison

This example exercises the product. It does not define the team's agent or use case.

**Question:** How does speech speed affect clarity, perceived control, and task completion?

**Task:** Find an appointment in a dedicated test calendar. Then add a practice appointment after spoken approval. Do not add attendees or send invitations.

**Conditions:** Condition A uses speed 0.85. Condition B uses speed 1.15. Keep the model, voice, prompt, language, tools, devices, and approval policy fixed. Use a new provider session for each condition.

**View:** Use Researcher view for a researcher who takes part. Record researcher participation. If the study needs Participant view, select it in both conditions. Keep results from different views separate by default.

**Procedure:** Complete a technical pilot first. Use matched tasks and AB/BA order. Record the calendar timezone. Before approval, convert relative dates to calendar dates.

**Evidence:** Record task outcomes, recovery events, interruptions, and defined timing measures. Collect the selected ratings. Keep tool failures and service variability with the results.

**Interpretation:** Show sample counts and missing values. Do not call a condition optimal. Select a configuration for further use only with an explanation of the available evidence.

The interface figures contain example data. Their counts do not determine a study sample size.
